# CPA 周与账期权益验收

## 页面

本地合成演示通过界面登录、进入 CPA 参与者页、打开账期配置并保存。演示中的四周场景明确标为合成示例，线上日期由真实账期配置计算。

- 1440 × 1000 深色：周分布、账期容量来源与累计消费同时显示；三张成员卡同一行，宽 341 px、x 坐标 321 / 678 / 1035，姓名颜色一致。
- 390 × 844 浅色：成员卡转单列（宽 310 px），图例与操作按钮换行，页面 `scrollWidth` 和视口均为 390 px，无横向页面溢出。
- 未配置账期显示管理员配置入口；配置后出现容量、失效、预计可用、周期来源及个人建议。未知周容量保留已采集费用和上游剩余百分比，不画成可用余额。
- 零值的未归属／历史成员图例隐藏，存在消费时单列。颜色之外始终保留姓名、金额和百分比；超额进度显示实际百分比。
- 页面无浏览器控制台 error。额度总览与统计页选择 CPA 账号后，均确认显示相同的周分布、账期分布和成员累计卡；原有 Sub2API 统计仍正常展示。
