# 时变额度粒子滤波

本文只定义正式时变模型的假设、输入输出和安全边界。代码结构见 [architecture.md](architecture.md)。

## 变量

- $C_i(t)$：主体 $i$ 从归属区间起点累计产生的美元成本。
- $V(t)$：时刻 $t$ 的隐藏等效总周限，当前正式模型限定为 $1400\le V(t)\le4000$。
- $q_i(t)$：主体 $i$ 的累计隐藏进度，单位为百分点。
- $P(t)=\sum_i q_i(t)$：隐藏总进度。
- $Z(t)$：上游显示的整数进度。
- $h_i$：主体的合同权益百分点。

成本增量按发生时刻的周限换算：

$$
dq_i(t)=\frac{100\,dC_i(t)}{V(t)}.
$$

## 观测假设

- $V(t)$ 连续变化，且始终位于硬范围内。
- 成本累计值非负、单调，精度为美分。
- 整数显示规则在同一归属区间内固定，但可能是向下取整、四舍五入或向上取整。
- 正式算法只使用当前及以前的观测。
- 第一阶段只在同时取得成本和整数百分比的正式观测点更新模型。

这些是假设，不是平台内部机制的声明。

## 粒子状态

每个粒子维护：

- 当前 $V(t)$；
- 每个主体的 $q_i(t)$；
- 一种变化速度尺度；
- 一种整数显示规则；
- 当前权重。

固定研究参数：

| 参数 | 值 |
|---|---:|
| 粒子数 | 480 |
| 周限范围 | 1400～4000 美元 |
| 速度尺度 | 6、24、72 小时 |
| 潜变量平稳标准差 | 0.60 |
| 区间消费时间 Dirichlet 参数 | 0.8 |
| 整数观测软误差 | 0.05 个百分点 |
| 最大内部子步 | 6 |
| 重采样阈值 | 有效粒子低于 50% |
| 概率区间质量 | 90% |
| 余额区间膨胀 | 1.3 |
| 输出惯性 | 0 |

这些参数来自独立开发集；普通业务设置不得修改。标准范围扩到 1400～4000 美元后，算法版本升为 `particle_filter_v3`，并对新范围重新校准。

首个历史区间从 $1400$～$4000$ 的宽分布初始化。正常进入新周期时，以上一周期最终容量估计为中心、120 美元为标准差初始化；它只提供软先验，新周期观测仍会更新结果。只有完全没有历史时才使用宽分布。

## 更新过程

对每个新观测：

1. 按观测间隔和粒子的速度尺度推进 $V(t)$；
2. 把各主体成本增量随机分布到区间内部子步；
3. 累加每个粒子的 $q_i(t)$；
4. 计算粒子总进度与三种整数显示单元的距离；
5. 按软似然更新权重；
6. 有效粒子不足时执行系统重采样；
7. 输出加权中位数和 90% 区间。

固定随机种子保证重放幂等。

## 余额输出

粒子内主体剩余余额为：

$$
B_i(t)=\max(h_i-q_i(t),0)\frac{V(t)}{100}.
$$

概率点估计先投影到确定性逐主体边界与总进度边界的交集，使输出不落在已知不可能区域；投影采用最小欧氏改动，不重新分配原始成本。余额再由投影后的归属与容量点估计计算。概率余额区间膨胀 1.3 倍后与确定性范围相交；若两者不相交，则回退到确定性范围。最终人工建议再应用业务安全系数。

已归属点估计不强制等于显示整数。显示整数只是对隐藏总进度的观测。

## 确定性范围

确定性外层范围只使用：

- 周限硬范围；
- 美分舍入误差；
- 三种可能的整数显示单元；
- 成本与进度单调性。

它不使用概率速度模型，因此通常比粒子区间宽。它用于约束点估计和区间；输入事实彼此不相容时会保守向外修复，并在诊断中记录，不能把修复后的宽区间解释成精确结论。

## 诊断

每个正式观测至少保存：

- 三种显示规则概率；
- 三种速度尺度概率；
- 有效粒子比例和是否重采样；
- 当前周限点估计和区间；
- 概率区间与确定性范围；
- 算法版本和稳定种子。

区间过宽或有效粒子过低表示不确定性升高，不表示上游发生了确定异常。

## 研究边界

1400～4000 美元标准范围使用 180 个冻结调参案例校准，并在 768 个极端连续测试案例、96 个十分钟高频案例和 384 个有限对抗案例上验证。粒子滤波的平均轨迹 MAE 分别为 185.83、163.80 和 188.20 美元，在所比较方法中均最低；混合后备没有改善总体结果。极端测试的概率区间平均覆盖率约 83.9%，这只是有限模拟结果，不是真实覆盖保证。

动态扩边另用 400 个范围内外案例研究。建议先在前两项证据同时成立时启动单侧影子滤波：最近 5% 边界带内至少聚集 10% 粒子；基础模型对整数显示单元产生同方向、超过 0.1 个百分点的矛盾。只有影子滤波中位数进一步越过硬边界至少 25 美元时才正式扩边。冻结测试中，范围内误扩率为 0%，可观测越界检出率为 93.88%，首次可观测矛盾后的平均检出延迟为 0.91 小时；混合测试 MAE 从 124.41 降至 114.47 美元。没有产生观测矛盾的真实越界不可被算法识别。

单个影子滤波运行期间约使计算量变为 2 倍；按上述条件按需启动时，混合测试平均增量约为 10.2%，且不增加上游请求。该扩边策略目前只是研究建议，`particle_filter_v3` 仍使用固定硬范围；正式接入前需要补齐状态持久化、重放和审计语义。

研究评价是开放环估计；管理员应用余额后形成的闭环消费行为尚未证明最优。因此后台继续只给建议，不新增自动调额。
