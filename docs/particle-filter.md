# 时变额度粒子滤波

本文只定义正式时变模型的假设、输入输出和安全边界。代码结构见 [architecture.md](architecture.md)。

## 变量

- $C_i(t)$：主体 $i$ 从归属区间起点累计产生的美元成本。
- $V(t)$：时刻 $t$ 的隐藏等效总周限。标准范围为 $1400\le V(t)\le4000$，持续越界证据可触发单侧分级扩张。
- $q_i(t)$：主体 $i$ 的累计隐藏进度，单位为百分点。
- $P(t)=\sum_i q_i(t)$：隐藏总进度。
- $Z(t)$：上游显示的整数进度。
- $h_i$：主体的合同权益百分点。

成本增量按发生时刻的周限换算：

$$
dq_i(t)=\frac{100\,dC_i(t)}{V(t)}.
$$

## 观测假设

- $V(t)$ 连续变化，且始终位于当前已激活的硬范围内。
- 成本累计值非负、单调，精度为美分。
- 整数显示规则在同一归属区间内固定，但可能是向下取整、四舍五入或向上取整。
- 正式算法只使用当前及以前的观测。
- 第一阶段只在同时取得成本和整数百分比的正式观测点更新模型。

这些是假设，不是平台内部机制的声明。

## 粒子状态

每个粒子维护：

- 当前 $V(t)$；
- 每个主体的 $q_i(t)$；
- 一种变化速度尺度；
- 一种整数显示规则；
- 当前权重。

固定研究参数：

| 参数 | 值 |
|---|---:|
| 粒子数 | 480 |
| 标准周限范围 | 1400～4000 美元 |
| 速度尺度 | 6、24、72 小时 |
| 潜变量平稳标准差 | 0.60 |
| 区间消费时间 Dirichlet 参数 | 0.8 |
| 整数观测软误差 | 0.05 个百分点 |
| 最大内部子步 | 6 |
| 重采样阈值 | 有效粒子低于 50% |
| 概率区间质量 | 90% |
| 余额区间膨胀 | 1.3 |
| 输出惯性 | 0 |

这些参数来自独立开发集；普通业务设置不得修改。`particle_filter_v6` 沿用 1400～4000 美元标准范围和经独立复现实验确认的分级扩张，把同一官方窗口的 `reset_at` 漂移容忍范围保持为 10 分钟，并在重放时把同一查询窗口内因旧容差误标的重复 `window_total` 还原为快照差值，避免累计成本被重复相加。

首个历史区间从 $1400$～$4000$ 的宽分布初始化。正常进入新周期时，以上一周期最终容量估计为中心、120 美元为标准差初始化；它只提供软先验，新周期观测仍会更新结果。只有完全没有历史时才使用宽分布。

## 更新过程

对每个新观测：

1. 按观测间隔和粒子的速度尺度推进 $V(t)$；
2. 把各主体成本增量随机分布到区间内部子步；
3. 累加每个粒子的 $q_i(t)$；
4. 计算粒子总进度与三种整数显示单元的距离；
5. 按软似然更新权重；
6. 有效粒子不足时执行系统重采样；
7. 输出加权中位数和 90% 区间。

固定随机种子保证重放幂等。`particle_filter_v6` 只更新周期边界、成本账本归一化与重放版本，继续使用已验证的 v4 随机流，避免未受这些变化影响的区间仅因元数据版本升级而改变估计；只有粒子模型本身变化时才升级种子版本。

## 分级扩张

模型每个归属区间都从 1400～4000 美元开始。一次正式观测必须同时满足两项证据才升级范围：

- 最近 5% 边界带内的后验质量至少为 10%；
- 估计累计进度相对三种整数显示规则的并集单元产生同方向、超过 0.05 个百分点的矛盾。

首次触发只扩张证据指向的一侧。向上依次为 6000、10000、20000；向下依次为 700、250、50。每一级都用该范围重放本区间全部观测；同方向双证据仍成立才进入下一级。区间内不自动缩界，也不切换到另一侧。

页面使用分段结果：触发前保留标准范围输出，触发点起采用新范围的重放输出。扩张状态由原始事实和稳定种子确定，并随每条观测写入诊断，因此重启和完整重放结果一致。

## 收缩策略

这里的“收缩”只指把已经扩大的粒子搜索范围缩回较窄一级，不是降低当前周限点估计。

同一归属区间内不自动收缩。扩张范围保持到该区间结束；确认官方重置或人工周期边界后，新区间重新使用 1400～4000 美元标准范围。原因是当前观测只能说明容量此刻可能回到窄范围，不能区分暂时回归与随后再次越界；过早收缩会删除仍可能成立的外侧路径，并可能触发重复扩张。

该规则经独立实验确定：开发与冻结阶段在 800 个连续轨迹案例中比较 378 个因果候选，随后用 600 个新种子案例确认。当前不收缩策略的参与者余额 MAE 为 115.889 美元；最佳自动收缩候选为 116.629 美元，候选减基准为 0.740 美元，95% Bootstrap 区间为 [0.203, 1.269]。四个入选候选均显著更差，因此不增加周期内自动收缩。

恢复标准范围只由新区间边界触发，不能由点估计回落、可信区间重新落入标准范围或边界粒子质量下降单独触发。

## 余额输出

粒子内主体剩余余额为：

$$
B_i(t)=\max(h_i-q_i(t),0)\frac{V(t)}{100}.
$$

概率点估计先投影到确定性逐主体边界与总进度边界的交集，使输出不落在已知不可能区域；投影采用最小欧氏改动，不重新分配原始成本。余额再由投影后的归属与容量点估计计算。概率余额区间膨胀 1.3 倍后与确定性范围相交；若两者不相交，则回退到确定性范围。最终人工建议再应用业务安全系数。

已归属点估计不强制等于显示整数。显示整数只是对隐藏总进度的观测。

## 确定性范围

确定性外层范围只使用：

- 周限硬范围；
- 美分舍入误差；
- 三种可能的整数显示单元；
- 成本与进度单调性。

它不使用概率速度模型，因此通常比粒子区间宽。它用于约束点估计和区间；输入事实彼此不相容时会保守向外修复，并在诊断中记录，不能把修复后的宽区间解释成精确结论。

## 诊断

每个正式观测至少保存：

- 三种显示规则概率；
- 三种速度尺度概率；
- 有效粒子比例和是否重采样；
- 当前周限点估计和区间；
- 概率区间与确定性范围；
- 算法版本和稳定种子。
- 当前激活范围、扩张级别、方向和历次触发证据。

区间过宽或有效粒子过低表示不确定性升高，不表示上游发生了确定异常。

## 研究边界

基础滤波在 768 个极端连续案例、96 个十分钟高频案例和 384 个有限对抗案例中优于所比较方法；有限模拟不能替代真实覆盖保证。

扩张范围另经两轮独立实验验证。确认集包含 800 个常规案例和 320 个远端越界压力案例。粗粒度分级扩张在常规案例中与原 6000/700 一次扩张基本相同（余额 MAE 差 0.003 美元），在尾部压力案例中平均少错 24.377 美元；永久使用 50～20000 明显更差。

越界若未产生成本或整数百分比矛盾，任何仅使用这些观测的在线算法都无法及时发现。研究评价仍是开放环估计；后台不会因此新增自动调额。

补充生产实现消融使用 300 个开发案例、600 个独立确认案例和 30 个多种子案例，直接调用生产滤波与投影代码。确定性投影对确认集 MAE 的影响为 +0.036 美元，95% Bootstrap 区间为 -0.015～+0.090 美元；它不提升平均精度，但以近乎零误差代价维持确定性可行性，因此保留。

当前 480 粒子和固定 1.3 余额区间膨胀仍是 `particle_filter_v6` 的实际参数。补充实验给出的下一版候选是 960 粒子，以及扩张状态相关区间：第一级上扩用确定性外包络、第一级下扩用 1.3、第二级以上用 1.0。候选区间在独立确认集覆盖 95.04%，按案例 Bootstrap 95% 区间为 94.20%～95.81%；在版本升级和完整重放落地前，不得把该候选描述成当前行为。

完整研究顺序、实验入口和冻结结果见 [study/README.md](study/README.md)。
