# 时变额度粒子滤波

本文只定义正式时变模型的假设、输入输出和安全边界。代码结构见 [architecture.md](architecture.md)。

## 变量

- $C_i(t)$：主体 $i$ 从归属区间起点累计产生的美元成本。
- $V(t)$：时刻 $t$ 的隐藏等效总周限，满足 $1400\le V(t)\le2100$。
- $q_i(t)$：主体 $i$ 的累计隐藏进度，单位为百分点。
- $P(t)=\sum_i q_i(t)$：隐藏总进度。
- $Z(t)$：上游显示的整数进度。
- $h_i$：主体的合同权益百分点。

成本增量按发生时刻的周限换算：

$$
dq_i(t)=\frac{100\,dC_i(t)}{V(t)}.
$$

## 观测假设

- $V(t)$ 连续变化，且始终位于硬范围内。
- 成本累计值非负、单调，精度为美分。
- 整数显示规则在同一归属区间内固定，但可能是向下取整、四舍五入或向上取整。
- 正式算法只使用当前及以前的观测。
- 第一阶段只在同时取得成本和整数百分比的正式观测点更新模型。

这些是假设，不是平台内部机制的声明。

## 粒子状态

每个粒子维护：

- 当前 $V(t)$；
- 每个主体的 $q_i(t)$；
- 一种变化速度尺度；
- 一种整数显示规则；
- 当前权重。

固定研究参数：

| 参数 | 值 |
|---|---:|
| 粒子数 | 320 |
| 周限范围 | 1400～2100 美元 |
| 速度尺度 | 6、24、72 小时 |
| 潜变量平稳标准差 | 0.78 |
| 区间消费时间 Dirichlet 参数 | 0.8 |
| 整数观测软误差 | 0.15 个百分点 |
| 最大内部子步 | 6 |
| 重采样阈值 | 有效粒子低于 50% |
| 概率区间质量 | 90% |
| 区间膨胀 | 1.0 |
| 输出惯性 | 0 |

这些参数来自冻结开发集，不能作为普通业务设置任意修改。参数变化必须提升算法版本并重新验证。

首个历史区间从 $1400$～$2100$ 的宽分布初始化。正常进入新周期时，以上一周期最终容量估计为中心、120 美元为标准差初始化；它只提供软先验，新周期观测仍会更新结果。只有完全没有历史时才使用宽分布。

## 更新过程

对每个新观测：

1. 按观测间隔和粒子的速度尺度推进 $V(t)$；
2. 把各主体成本增量随机分布到区间内部子步；
3. 累加每个粒子的 $q_i(t)$；
4. 计算粒子总进度与三种整数显示单元的距离；
5. 按软似然更新权重；
6. 有效粒子不足时执行系统重采样；
7. 输出加权中位数和 90% 区间。

固定随机种子保证重放幂等。

## 余额输出

粒子内主体剩余余额为：

$$
B_i(t)=\max(h_i-q_i(t),0)\frac{V(t)}{100}.
$$

正式点估计采用粒子加权中位数。概率区间采用对应分位数，并与确定性范围相交；如果概率区间失效，则回退到确定性范围。最终人工建议再应用业务安全系数。

已归属点估计不强制等于显示整数。显示整数只是对隐藏总进度的观测。

## 确定性范围

确定性外层范围只使用：

- 周限硬范围；
- 美分舍入误差；
- 三种可能的整数显示单元；
- 成本与进度单调性。

它不使用概率速度模型，因此通常比粒子区间宽。它用于约束明显不可能的结果和模型退化时的安全展示，不用其中点替代粒子滤波。

## 诊断

每个正式观测至少保存：

- 三种显示规则概率；
- 三种速度尺度概率；
- 有效粒子比例和是否重采样；
- 当前周限点估计和区间；
- 概率区间与确定性范围；
- 算法版本和稳定种子。

区间过宽或有效粒子过低表示不确定性升高，不表示上游发生了确定异常。

## 研究边界

极端连续模拟中，本方法在已比较基础方法里平均误差最低，但不是可证明的唯一真值。极端测试的概率区间覆盖率曾下降到约 67%，因此页面不得把模型区间宣传为保证覆盖的“90%真实范围”。确定性范围才承担硬约束解释。

研究评价是开放环估计；管理员应用余额后形成的闭环消费行为尚未证明最优。因此后台继续只给建议，不新增自动调额。
