# 科研共创：运行、授权与隐私

默认关闭。管理员在独立 `settings/research` 接口和设置卡片保存授权；普通用户不能读/写科研摘要，原通用设置PATCH不能开启该功能。

主开关、项目列表、接收网站、用量覆盖确认参与授权摘要；方法或告知内容变化会使已有授权失效。间隔1..168小时（默认6），关闭不依赖其他字段合法性，可单独 `PATCH {"enabled":false}`。空地址只做本地分析，无DNS查询或HTTP连接。

容器入口新增独立的 `python manage.py runresearch` 子进程，每30秒检查调度；不阻塞主监控。手工部署需单独托管该进程或定时运行 `manage.py runresearch --once`。状态接口不会因为GET而分析或上传。任务带15分钟租约、配置版本、发送前再检查授权；关闭后停止新发送，已经被网络层接纳的请求可能完成。网络失败只保留通用错误和退避，不记录上游响应正文或异常中的地址。

原始分项只在有效授权期间随已存在的Sub2API请求采集，放入独立表，缺字段不破坏业务采集。分析不新增上游调用。缺少分项的事实不会猜测。批次持续重算并保留，报告是可重建缓存，不是计费权威事实。配置页面显示规模、支持或失败状态及即将分享摘要。

## 传输内容

仅固定统计字段与方法、随机网站隔离公钥、批次标识、递增revision及签名。无模型别名、精确时间序列、原始请求、Prompt或回答、Token明细、用户名、账号ID、API Key、Sub2API地址或IP字段。没有本地样本量或置信度发送门槛；无区分信息的报告仍可贡献规模和质量状态。

IP在直接联网时仍被接收网站/反向代理看到；接收应用不记录IP不意味着托管/CDN都不记录。随机公钥可关联同安装更新，是去标识化不是不可关联。不是差分隐私，合并少量安装可能仍泄露统计特征。

HTTPS根地址不接受路径、用户密码、query或fragment。DNS全部解析地址须为公网，连接固定校验后的IP并用原域名验证TLS；禁止重定向，不使用环境代理、浏览器Cookie、Sub2API令牌或指纹User-Agent。响应和请求大小、连接/读取时间都有上限。localhost仅在测试覆盖设置中显式允许，生产没有对应开启环境变量。

## 重试、长期保留与备份

每个接收网站使用独立随机键和批次标识。同批次报告替换，相同统计不重复发送，失败重试使用更高revision。服务器校验签名与递增序号，不能由另一个键覆盖同一贡献。

关闭科研只停止后续发送；已经提交的不同批次由接收网站长期保留。更换网站会使用不同公钥，原网站上的贡献不会自动删除。

数据库导入会清除授权并停止任务；可解密身份继续用于同站点去重，不可解密身份会重置本地发送状态。手工复制活跃数据卷或直接还原备份绕过导入接口时，需部署者先关闭科研并重新同意；不要让多个活跃实例共享同一密钥revision序列。研究数据增加存储，备份包含本地原始分项与加密私钥，应按敏感数据保管。

## 故障与验证

`destination_unconfigured`：空地址，仅本地分析。
`no_data`：没有可提交批次。
`delivery_failed`：失败后自动退避，额度监控不受影响。
`analysis_failed`：本地分析失败，原始事实和已提交贡献不受影响。

GitHub CI运行独立数据与签名模拟接收端；不会与实际生产Sub2API/研究网站连接，不上传数据库、私钥或真实请求。研究方法的模拟实验结果只能用于检查实现与假设敏感性，不能证明官方订阅计费机制。
