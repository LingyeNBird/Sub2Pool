# 时变算法迁移

本文记录从累计分位算法切换到混合粒子滤波时必须满足的迁移合同。

## 替换内容

旧时变模型：

```text
累计成本 / 显示百分比 → 历史保守分位 → 区间成本比例归属
```

新时变模型：

```text
成本轨迹 + 整数百分比序列 → 混合粒子滤波 → 确定性边界 → 参与者余额
```

“平均恒定”和简单统计不更换算法。

## 数据处理

迁移只增加或重建派生字段，不删除原始采样。算法版本提升后，从每个账号最早受影响区间重放。重放期间：

- 不访问 Sub2API 写接口；
- 不发送历史通知；
- 不清除排除、人工起点和一键应用记录；
- 不改变合同权益和用户绑定。

升级前必须创建完整数据库备份。回退旧镜像时应同时恢复升级前数据库，避免旧代码读取新派生语义。

## 预期变化

以下历史结果会变化：

- 时变模型的美元/1%和总周限；
- 参与者已归属百分比；
- 剩余权益和建议余额；
- 相关计算依据和通知判断。

以下结果不因粒子滤波改变：

- 原始观测；
- 本周期累计折算、今日用量折算、累计收盘和日内折算；
- 平均恒定模型；
- 用户、权限和部署配置。

## 设置迁移

旧时变模型专用设置“保守分位数”和“参与计算的历史样本数”从页面和 API 移除。粒子滤波研究参数由算法版本固定。安全系数、成本口径、采样策略和建议阈值继续保留。

## 验收

迁移必须证明：

1. 原始事实迁移前后完全一致；
2. 相同数据重复重放结果一致；
3. 全量重放与逐条追加结果一致；
4. 简单统计和平均恒定回归结果不变；
5. 未解释成本未分配给已有参与者；
6. 普通用户权限不扩大；
7. 历史重放不发送通知或写入余额；
8. 新旧数据库导入导出行为明确。
