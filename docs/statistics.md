# 统计口径

本页定义独立于分配模型的描述性统计。它们用于复核观测，不决定参与者余额。

设区间起止累计成本为 $C_0,C_1$，显示进度为 $P_0,P_1$。

## 本周期累计折算

使用当前归属区间起点和最新观测：

$$
\widehat V_{cycle}=\frac{C_1-C_0}{P_1-P_0}\times100.
$$

它表示区间至今的平均折算，不代表时变模型估计的当前周限。分母不为正时不输出。

## 今日用量折算

使用当天同一归属区间内最早和最晚观测：

$$
\widehat V_{day}=\frac{C_1-C_0}{P_1-P_0}\times100.
$$

观测不足两条、成本没有正向变化或百分比跨度低于设置阈值时，显示样本不足。整数百分比导致的简单上下界继续按端点误差计算。

## 累计收盘

每天取最后一次有效观测，以归属区间起点到该收盘点计算 `本周期累计折算`。月度图使用每日收盘结果聚合。它不读取粒子滤波状态。

## 日内折算

每天以首末有效观测计算 `今日用量折算`。跨越归属区间的日期不得拼接计算。

## 模型当前估计

粒子滤波输出的当前等效周限是另一项指标，必须以“当前模型估计”单独展示。不得用它覆盖上述四项统计，也不得把上述简单统计作为参与者余额建议。

## 账号用量明细

Sub2API 账号按参与者与上游 API Key 展示已保存的用户用量事实。CPA 账号没有参与者、余额或建议，改为按本地 HMAC 后的 API Key 分组展示请求数、Token 和按当前价格配置动态计算的估算成本；页面只显示末尾四位提示，不能恢复原始 Key。未知模型按 0 美元汇总，并单独显示未计价请求数。

CPA 统计只覆盖监控账号在 RESP 订阅成功后收到并持久化的 usage 事件。订阅期间原有定时百分比请求照常执行；连接建立前与断线期间的请求不推测、不回填。账号连接覆盖由独立采集区间保存，不从百分比观测推断。订阅后的 opening 百分比与取消订阅前的 closing 百分比只是可选数值样本；最终 RESP `PING` 确认截止点前的直播事件已进入持久队列后，独立结束事件关闭采集区间。数据库 busy 时持续重试；异常退出按最后持久心跳记录不可靠截止点且不伪造 closing 观测。断线期间产生的普通观测只保留审计事实，不把缺口当成零成本连续用量。CPA 成本也不会应用 Sub2API FAST 事后修正。

## 计算依据

简单统计的依据只展示：

- 起点和终点时间；
- 起止成本及成本明细；
- 起止显示百分比；
- 差值公式；
- 最小跨度和整数误差范围。

不在简单统计的依据弹窗中解释粒子、后验概率或模型速度。
