# GPT-6 原始证据联合共研

方法 ID：`pooled-profile/raw-only`。规范参数见 `backend/monitor/research/pooled_descriptor.json`；客户端副本必须逐字段相同。

## 最终决定：不上传、不读取、不使用容量估值

粒子滤波、平均恒定模型及其他运行额度估值全部不进入科研协议或计算。没有“辅助容量通道”，也不在中心混合这些估值。旧实验比较过这类方法，实验记录不删改，但不是上线功能。各账号短片段的未知比例参数由原始观测剖面消去；这不是借用运行额度测算结果。

## 科研问题与固定控制条件

只研究 GPT-6 输入、缓存创建、缓存读取、输出的四项倍率 β。FAST 正确目标固定2，GPT-5.6/GPT-6长上下文不增加额外倍率（目标1），其他模型既有计费假定正确。源倍率使用用户声明的 Sub2API 源配置归一：已被源2倍计费的FAST不再乘2；源长上下文2倍的GPT请求除2。GPT-6运行全局1.8、FAST运行目标2.5不作为研究答案。其他科研项目独立声明前提，不自动相互修改。

升级后的旧观测使用其冻结的源规则。新上游计价可能包含分组、渠道及模型价格；仅凭请求总价无法恢复完整参考控制成本，因此当前将这些新区间标为 `unknown_control`，不生成虚构的倍率证据，请求规模仍可贡献。

对原始额度观测区间，已知控制成本 K 和 GPT-6 四分项成本 X，候选有效成本为 S(β)=K+Xβ。所有成本使用原始标准口径，不混用实际折扣美元。对应原始额度增量为 y（百分点）。混用其他模型、FAST、长上下文本身不是排除条件。

只有缺少必要原始事实、源倍率判断不明、覆盖断裂、原始重置/饱和无法解释时，相应区间不生成伪造证据；请求量仍可贡献。未确认完整用量覆盖也接收并标记。模型匹配限定 `gpt-6` 后接点、横线或结束，不误匹配 gpt-60。

## 无样本准入门槛

不要求请求数、周期数、区间数、参与安装数、本地信息秩或本地高置信度。允许1条甚至仅有零规模的有效状态报告。上限（请求体256KiB、计算分段32段/6小时、20批次/次任务）是资源管理，不是科研准入条件。更多待发批次下次任务继续；历史不会因超限被删除。

无对应额度的请求贡献统计规模；有单区间但容量完全自由时，主证据平坦。没有对比信息不代表拒收：后续同批次追加区间会替换摘要、产生新信息。多个局部秩不足的来源可以联合达到更高秩。只用GPT-6时整体倍率与容量尺度可能不可辨识，完全共线分项也不能凭空拆开。

## 共同参数证据与一次先验

固定网格1311点：四分项各取 {0.5,1,1.5,1.75,2,3}，额外单项/整体1.25、1.8、2.5，按字典顺序排列。分类为不变、整体、缓存读、缓存创建、输出、输入、混合。中心每族先验1/7，族内均匀。1.8只是候选之一，不是预定结果。

一个账号同周期内的连续短片段最多32个区间、6小时；缺口分开。令 Z 的行是(K,X四项)，v=(1,β)，y为原始额度增量。共用的工作协方差 V 包含增量量化方差1/6、对角误差底值0.01、共享端点协方差−1/12。设区间中点相对首中点的时间为t，d=max(y,0.5)，漂移项为 σ² diag(d) min(t_i,t_j) diag(d)。分别使用σ=0、0.15、0.4；中间为默认，另两项只作**原始数据误差假设**敏感性，不是任何PF估值。

W=V⁻¹，G=ZᵀWZ，h=ZᵀWy，q=yᵀWy。每候选剖面残差：

```
a_hat = max(vᵀh,0)/(vᵀGv)
R = max(0, q - max(vᵀh,0)²/(vᵀGv))
log_evidence = -0.5 × (4+n−1)/2 × log(1+R/4)
```

扣掉不变候选的常数后上传。片段只一个观测时返回平坦曲线（包括零增量情况），不为它生成错误的精确信息。共享货币单位缩放不改变曲线。

**客户端不挑赢家、不加先验、不发送本地置信百分比。中心先对同一β累加所有片段/批次的对数证据，再加一次先验。** 之后按族求和得到支持度，按网格给出分项加权均值和边缘5%/95%分位数。信息矩阵用于全局秩和来源集中诊断，不设本地拒收门槛。零曲线不展示先验伪装的“研究结果”。

## GPT-6 区间额度归因

给定候选β，归因量是 `y × Xβ / (K+Xβ)`。本地将它按候选汇总成一条曲线，不上传区间明细。中心以联合证据权重给出总归因量和范围。这是候选模型下的推导，不是另一个独立标签，绝不拿来再次训练同一β。

## 支持度、独立性与失效边界

这里是 Student 型工作损失的广义条件证据分布，不是已校准的官方计费概率。更大的独立互补样本有助于减少随机误差；共同漏记、来源复制、容量变化与模型选择系统性相关、错误控制前提不会被“人多”自动解决。相同来源内分段也不保证完全独立，可能高估证据强度。页面保留敏感性、信息秩、最大来源信息占比和固定前提提醒，不以警告拒收数据。

原11页实验报告及逐次CSV保留。比较实验结果仍可审阅，尤其保留容量与模型选择相关时错误高支持的反例。实现另有独立标量GLS对照、缩放不变性、局部秩一合成互补、跨语言网格和真实Python到Go联调。

## 批次与递增序号

本地批次以账号和官方周期组织，但对外只有网站隔离的随机批次ID，无账号ID、原始日期和时间线。一个批次的更新替换自身记录；不同批次持续保存；不因120天不活跃、导入或停用而删除。签名身份与递增revision防重放。

本地原始来源被删除或矛盾时，保留此前可复现的摘要并显示归档提示，不悄悄用空数据覆盖贡献；不能声称已更新缺失来源的证据。批次重复或跨安装共享账号仍有潜在重复风险，随机签名不是独立自然人证明。

## 部署

接收端和客户端必须使用相同的协议、方法文件、路径与签名域。默认接收地址只在管理员明确授权后使用；自定义和空地址保持原值，科研默认关闭。旧原始请求缺少分项时不回推价格。

批次原始ID和账号周期仅存本机，发送时使用网站隔离身份派生UUID。成功回执按站点、身份、方法和摘要哈希保存；失败可重试。关闭科研只停止后续发送，已经提交的批次由接收网站长期保留。
